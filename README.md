# 🇮🇳 ERPNext Indian GST E-Invoice & E-Way Bill Bridge

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-v14%20%7C%20v15-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A statutory compliance gateway for **ERPNext** integrating Indian **GST E-Invoicing (IRN generation) & E-Way Bill** generation via NIC / GSP APIs. Generates compliant SHA-256 IRN hashes, signs B2B invoice payloads, and embeds signed QR codes into Frappe print formats.

---

## ⚡ Features
- 🛡️ Statutory NIC v1.1 JSON format builder for Sales Invoices.
- 🔐 SHA-256 IRN (Invoice Reference Number) hashing engine.
- 🚚 E-Way Bill vehicle tracking and distance calculation integration.
- 🧪 Pytest test suite included.
